VerKV：带 (ε, δ) 误差保证的 KV cache 压缩

VerKV 在 GPU 上保留一组与查询无关的关键 token 及全量 KV cache 的 token 级草图，完整缓存放在 CPU 内存。推理时先估计注意力的相对误差，满足用户设定的 (ε, δ) 容限就不访问主机内存，否则按查询从 CPU 取回更多 token，以降低长上下文场景的传输延迟。
